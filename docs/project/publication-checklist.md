# Checklist penyerahan dan publikasi

Checklist ini dipakai sebelum mengumpulkan hasil. Bagian publikasi hanya
berlaku jika kelompok memutuskan atau diminta memublikasikan repo/hasil.
Keberadaan dokumen ini tidak mengubah visibilitas repository.

## Kesesuaian tugas

- [ ] Identitas kelompok/anggota benar dan keluaran sesuai tahap yang diminta.
- [ ] Sumber, karakteristik data, tujuan/BOD, metode, dan batas ABSA jelas.
- [ ] Artikel berbahasa Indonesia dan format mengikuti template dosen.
- [ ] Nama aspek, label, unit analisis, serta istilah konsisten antardokumen.

## Kode, eksperimen, dan angka

- [ ] Cara memperoleh data dan menjalankan kode tertulis.
- [ ] Versi data, library, konfigurasi, seed, dan pembagian data tercatat.
- [ ] Hasil prediksi dapat dipasangkan dengan label acuan yang sesuai.
- [ ] Angka pada grafik, laporan, artikel, dan slide sama dengan rekap hasil.
- [ ] Validasi/CV dan uji final dibedakan; keterbatasan evaluasi dijelaskan.
- [ ] CI terakhir diperiksa dan notebook/pipeline ditinjau terpisah ketika
  digunakan. CI sintaks tidak menggantikan pengujian ABSA.

## Data, akses, dan dokumen

- [ ] Izin sumber memperbolehkan penggunaan/pembagian bentuk data yang dikirim.
- [ ] Tidak ada token/password atau identitas pribadi yang tidak diperlukan
  pada data, keluaran notebook, log, screenshot, dan lampiran.
- [ ] Tautan dapat dibuka oleh penerima yang dimaksud dan berkas final terbaca.
- [ ] Sumber edit, bukti eksperimen, serta cadangan materi tersedia.

## Tambahan jika repo/hasil akan dipublikasikan

- [ ] Tinjau seluruh riwayat Git dan branch terkait, bukan hanya versi terbaru,
  untuk kredensial, data pribadi, dan berkas yang tidak boleh dibagikan.
- [ ] Tinjau metadata commit serta dokumen/gambar yang ikut dipublikasikan.
- [ ] Pilih lisensi kode jika diperlukan; hak atas dataset tetap mengikuti sumber.
- [ ] Jika ada kebocoran, tangani sesuai [SECURITY.md](../../SECURITY.md)
  sebelum publikasi. Penulisan ulang riwayat dibahas bersama terlebih dahulu.

## Catatan pemeriksaan

| Tanggal / versi | Bagian diperiksa | Pemeriksa | Temuan / tindak lanjut | Bukti |
|---|---|---|---|---|
| Diisi sesuai pelaksanaan | Diisi | Diisi | Diisi | Tautan/path |

Kotak kosong adalah format pemeriksaan; bukan pernyataan bahwa kegiatan
tersebut sudah atau belum dilakukan oleh anggota.
