# Panduan kerja Web Mining Kelompok 2

## Prinsip kerja

Semua anggota berkontribusi pada setiap tahap. Bagi pekerjaan berdasarkan
kesulitan dan waktu aktual, tanpa PIC khusus. Daftar anggota, pembagian nama,
dan tanggal kelas diisi setelah informasinya tersedia.

Paket awal yang dapat dibagi: pengumpulan/eksplorasi; preprocessing/anotasi;
metode aspek/sentimen; evaluasi/visualisasi. Penulisan dan presentasi dibagi
sesuai kontribusi nyata, dengan pemeriksaan bersama.

## Roadmap

| Week | Keluaran tugas |
|---|---|
| 10 | Dataset, karakteristik, BOD, algoritma; scraping disarankan |
| 11-12 | Preprocessing, mining, evaluation |
| 13 | Laporan pertama |
| 14 | Percobaan tambahan jika diminta |
| 15 | Artikel bahasa Indonesia |
| 16 | Presentasi |

Tanggal serta tenggat Web Mining belum diberikan. Target kalender dan format
artikel mengikuti dosen, terpisah dari proyek Data Mining.

## Keputusan dan bukti

Catat pemilihan sumber, aspek, label, metode, pembagian data, dan metrik pada
dokumen tahap terkait. Hubungkan keputusan dengan sumber atau bukti.
Gunakan issue untuk tugas/masukan dosen dan PR untuk perubahan. Masing-masing
memperbarui status, kendala, serta tautan hasilnya.

Lihat [panduan kontribusi](../../CONTRIBUTING.md) dan
[review setup](review-setup.md).
