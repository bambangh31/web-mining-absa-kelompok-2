# Notebook

Rencana penamaan, dibuat saat diperlukan:

1. `00_pengumpulan_eksplorasi.ipynb`: pengambilan dan karakteristik data.
2. `01_preprocessing.ipynb`: pembersihan, transformasi, dan pembagian data.
3. `02_analisis_aspek.ipynb`: ekstraksi/kategori aspek sesuai lingkup tugas.
4. `03_sentimen_aspek.ipynb`: analisis sentimen pada aspek.
5. `04_evaluasi.ipynb`: evaluasi, visualisasi, dan analisis kesalahan.

Ini adalah rencana alur, bukan daftar hasil jadi. Sesuaikan struktur dengan
metode yang dipilih; gunakan fungsi bersama dari `src/` dan path relatif.
