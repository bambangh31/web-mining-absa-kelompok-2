# Dataset ABSA

Dataset belum dipilih. Setelah tersedia, catat sumber/link, tanggal akses,
izin, cara pengambilan, periode, bahasa, domain, jumlah teks, dan karakteristik.
Sertakan contoh teks, kamus kolom, kondisi data kosong/duplikat, serta batasnya.

- `raw/`: teks asli yang boleh disimpan/dibagikan.
- `processed/`: keluaran pembersihan dan transformasi.
- `annotations/`: panduan aspek/sentimen dan label acuan untuk evaluasi.

Tentukan apakah tugas mencakup menemukan aspek, mengklasifikasikan sentimen
pada aspek yang sudah diketahui, atau keduanya. Satu teks bisa memuat beberapa
aspek; dokumentasikan unit data dan cara menyimpan anotasinya.

Jika scraping dipilih, simpan kode/parameter, aturan pengambilan, dan sumbernya.
Data besar atau yang tidak boleh dibagikan ulang cukup dilengkapi petunjuk
pengambilan. Tentukan Git LFS setelah ukuran dan izin dataset diketahui.
