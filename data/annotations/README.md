# Panduan aspek dan label acuan

Tentukan aspek/kategori, bentuk anotasi, definisi sentimen, contoh penerapan,
dan cara menyelesaikan perbedaan anotasi. Catat sumber label bila dataset sudah
berlabel. Pisahkan label acuan dari prediksi model.

Format disepakati setelah dataset dan lingkup ABSA dipilih. Belum ada label
atau hasil anotasi yang ditetapkan oleh README ini.
