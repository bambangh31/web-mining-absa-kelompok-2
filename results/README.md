# Hasil eksperimen ABSA

- `metrics/`: skor dan konfigurasi eksperimen dari eksekusi nyata.
- `figures/`: visualisasi dan analisis kesalahan.

Catat versi kode/data, unit evaluasi, jenis set, dan sumber label acuan.
Pisahkan evaluasi ekstraksi/kategori aspek dari sentimen per aspek sesuai
lingkup yang dikerjakan; laporkan per aspek bila relevan.
